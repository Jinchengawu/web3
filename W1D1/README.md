# 工作量证明（Proof of Work）实现

## 功能描述

这个项目实现了工作量证明（Proof of Work）算法，通过不断修改nonce值来计算SHA256哈希，直到找到满足特定条件的哈希值。

## 实现功能

1. **4个0开头的哈希值挖掘**：不断尝试不同的nonce值，直到找到以4个0开头的SHA256哈希值
2. **5个0开头的哈希值挖掘**：继续挖掘，直到找到以5个0开头的SHA256哈希值
3. **性能统计**：记录每次挖掘的耗时、尝试次数、哈希率等信息

## 文件结构

- `pow.ts` - 主要的POW实现类
- `test-pow.ts` - 测试脚本，可以测试多个昵称
- `README.md` - 说明文档

## 使用方法

### 安装依赖

```bash
npm install
```

### 运行POW测试

```bash
# 运行单个POW测试
npm run pow

# 运行多个昵称的POW测试
npm run pow-test
```

### 直接使用TypeScript

```bash
# 编译TypeScript
npm run build

# 运行编译后的JavaScript
node dist/W1D1/pow.js
```

## 技术特点

2. **模块化设计**：清晰的类结构和接口定义
3. **性能监控**：实时显示挖掘进度和性能指标

5. **可扩展性**：易于修改难度级别和添加新功能

## 算法说明

1. 使用昵称 + nonce作为输入字符串
2. 计算SHA256哈希值
3. 检查哈希值是否以指定数量的0开头
4. 如果不满足条件，增加nonce值并重复步骤2-3
5. 记录找到满足条件哈希值时的所有统计信息

## 注意事项

- 5个0开头的哈希值比4个0开头的哈希值更难找到，耗时会更长
- 实际运行时间取决于计算机性能
- 建议在性能较好的机器上运行以获得更好的体验
